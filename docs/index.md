# Manual de Usuario — Sistema de Gestión de Correspondencia

Bienvenido al manual oficial del **Sistema de Gestión de Correspondencia** de la Corporación Centro de Estudios Regionales (CER).

Este manual está organizado por **tareas**, para que puedas encontrar rápidamente lo que necesitas según tu rol y lo que quieres hacer.

Documento llega → Se radica → Se imprime etiqueta → Se gestiona el estado → Se archiva
