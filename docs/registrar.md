# Registrar un nuevo radicado

!!! warning "Quién puede hacer esto"
Solo usuarios con rol **Administrador** u **Operador**.

## Pasos

1. En el menú lateral, haz clic en **Nuevo Radicado**.
2. Selecciona el **Tipo de correo**: Correo Recibido o Correo Enviado.
3. Selecciona el **Tipo de correspondencia**: Oficio, Memorando, Circular, Resolución, Acta, etc.
4. Ingresa el **Remitente** (persona o entidad que envía el documento).
5. Ingresa el **Destinatario** (opcional).
6. Escribe el **Asunto** del documento.
7. Selecciona el **Estado inicial** del radicado.
8. Adjunta el documento en **formato PDF** si lo tienes disponible (opcional).
9. Haz clic en **Guardar Radicado**.

El sistema asignará el número de radicado y generará el código de barras automáticamente.

---

## Formato del número de radicado

CER-[TIPO]-[AAAAMMDD]-####

**Ejemplo:** `CER-OF-20260311-0001` → Oficio del 11 de marzo de 2026, primer radicado del día.

!!! tip "El número es automático"
No puedes modificarlo manualmente. El sistema lo genera para garantizar unicidad e integridad.

---

## Sobre el destinatario

| Tipo de correo  | ¿Quién es el destinatario?                              |
| --------------- | ------------------------------------------------------- |
| Correo Recibido | La dependencia o funcionario interno al que va dirigido |
| Correo Enviado  | La entidad o persona externa a quien se dirige          |
