# Preguntas frecuentes

??? question "¿Puedo modificar el número de radicado?"
No. Es generado automáticamente por el sistema para garantizar unicidad, integridad y trazabilidad.

??? question "¿Qué pasa si selecciono el mismo estado al actualizar?"
El sistema detecta que no hubo cambio y no genera una nueva entrada en el historial.

??? question "¿Puedo adjuntar documentos en Word o imagen?"
No. El sistema acepta únicamente **archivos PDF**. Tampoco es posible reemplazar un adjunto una vez guardado el radicado — en ese caso contacta al administrador.

??? question "¿Qué hago si olvido mi contraseña?"
El usuario no puede restablecerla por su cuenta. Debes contactar al **Administrador del sistema** para que la restablezca desde el panel de administración.

??? question "¿El lector de código de barras funciona directamente?"
Sí. Conecta el lector USB, posiciona el cursor en la barra de búsqueda y escanea la etiqueta. El sistema ubica el radicado al instante.

??? question "¿Puedo exportar solo un período específico?"
Aún no. La exportación descarga siempre el listado completo. Para filtrar por período, usa Excel después de descargar. Esta función se mejorará en versiones futuras.

??? question "¿Se puede modificar o eliminar el historial de estados?"
No. El historial es **inmutable por diseño**. Ningún usuario puede modificarlo o eliminarlo, lo que garantiza la auditoría completa de cada documento.
