# Limitaciones y comportamientos conocidos

| Función                    | Comportamiento actual                                                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Editar un radicado**     | No disponible. Si hay datos incorrectos, el Administrador puede registrar una observación en el historial que aclare el error. |
| **Eliminar un radicado**   | No disponible. Los radicados son permanentes para garantizar trazabilidad documental.                                          |
| **Exportar con filtros**   | La exportación descarga siempre el listado completo, sin importar el filtro activo.                                            |
| **Tamaño del PDF adjunto** | Sin límite definido en v1.0. Se recomienda no superar **10 MB** para garantizar el buen funcionamiento.                        |
| **Sesión activa**          | Permanece activa 14 días si no se cierra manualmente. En equipos compartidos, cierra sesión siempre al terminar.               |
