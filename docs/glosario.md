# Glosario de términos

| Término                     | Definición                                                                                                |
| --------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Radicado**                | Registro formal de un documento que ingresa o sale de la institución, con número único de identificación. |
| **Número de radicado**      | Código alfanumérico único generado automáticamente. Formato: `CER-[TIPO]-[FECHA]-[CONSECUTIVO]`.          |
| **Tipo de correspondencia** | Clasificación del documento: Oficio (OF), Memorando (MEM), Circular (CIR), Resolución (RES), Acta (ACT).  |
| **Estado del radicado**     | Etapa de gestión actual: Recibido, En revisión, En trámite, En proceso, Respondido, Resuelto, Archivado.  |
| **Historial de estados**    | Registro cronológico e inmutable de todos los cambios de estado de un radicado.                           |
| **Código de barras**        | Identificador óptico generado automáticamente para cada radicado.                                         |
| **Sticker / Etiqueta**      | Impresión física del identificador del radicado con datos clave y código de barras.                       |
| **Dashboard**               | Panel principal con estadísticas en tiempo real del sistema.                                              |
| **Rol de usuario**          | Nivel de acceso: Administrador, Operador o Consultor.                                                     |
| **Exportar**                | Función para descargar el listado de radicados en PDF o Excel.                                            |
