# Roles y permisos

El sistema tiene tres roles. Tu rol lo asigna el Administrador.

| Rol               | Quién lo usa            | Qué puede hacer                                          |
| ----------------- | ----------------------- | -------------------------------------------------------- |
| **Administrador** | Alta dirección / TI     | Todo: crear usuarios, radicar, cambiar estados, exportar |
| **Operador**      | Personal administrativo | Radicar documentos, cambiar estados, exportar            |
| **Consultor**     | Directivos / auditores  | Solo consultar y buscar radicados                        |

!!! tip "¿No sabes tu rol?"
Comunícate con el administrador del sistema o con la supervisora del proyecto.
